# Venture Herd Manager — Current Backlog

## 1. Embryos and breeding — highest priority

- Investigate why an embryo can become unlinked.
- Pregnancy confirmation must correctly record whether an embryo stuck and resulted in pregnancy.
- When an animal is not pregnant, record that the embryo did not stick while preserving the implant result and history.
- Fix the failure when saving an embryo implant as a breeding.
- Add Edit to breeding records directly on the animal card so dates and details can be corrected.
- Add Edit and Delete to implanted embryo records for correcting entry mistakes.
- Make embryo cards collapsible.
- Clearly record implant outcomes as Successful or Failed.
- Support incomplete or unavailable service information: allow the record to be saved and completed later.

## 2. Pregnancy and analytics

- Ensure confirmed pregnancies are reflected correctly in Analytics.
- Correct the pregnancy analytics logic so Date Bred is checked and used properly.
- Add a Pregnancy Checks Due report.
- Add Pregnancy Checks Due status filters: Milking, Heifers, Dry, and All. Default to All.
- Add Print Report for pregnancy checks.
- Add sorting and filtering to Pregnancy Checks Due.
- Default the Due Within report to 30 days and allow switching to 60 days.

## 3. Animal records

- Allow calves to be entered without a barn name.
- Add a report for calves missing a barn name and/or registration number.
- Make newly created calves searchable immediately.
- When a heifer has no barn name, show a useful pedigree-based identifier such as Sire × Dam.

## 4. Reports

- Pregnancy checks due.
- Animals seven months or older that have not been bred.
- Milking cows not bred.
- Embryos implanted.
- All animals, sortable and filterable by group.
- Calves missing barn names and/or registration numbers.

## 6. Herd list
